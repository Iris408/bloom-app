# Bloom Illustration Pack 1.0

**Version:** 1.0  
**Status:** 🟡 In Review  
**Theme:** Core Identity

---

## Purpose

This document defines Bloom's visual identity and establishes the standards
that every future illustration should follow.

It serves as the reference for illustration style, character design,
environment, colours and emotional direction across the Bloom website,
web application, mobile application and marketing material.

---

# Bloom Values

Every illustration should reinforce one or more of Bloom's core values.

- Gentle Progress
- Calm
- Reflection
- Accessibility
- Community
- Growth
- Balance
- Rest
- Mindfulness
- Hope

Illustrations should support the user emotionally rather than simply decorate
the interface.

## Theme

Core Identity

## Goal

Establish Bloom’s visual identity through a small collection of flagship illustrations that define the product’s character, atmosphere, colours, environments and values.

Every future illustration should feel like it belongs in this collection.

## Desiign Principles

### Emotional Goal

Every illustration should leave the viewer feeling at least one of the following:

* Calm
* Safe
* Hopeful
* Encouraged
* Supported
* Reflective
* Comfortable

Never:

* overwhelming
* busy
* stressful
* competitive
* overly colourful

# Design Rules

Every illustration should:

- feel clean and uncluttered
- use generous whitespace
- include soft botanical elements where appropriate
- avoid visual noise
- maintain consistent lighting and colour grading
- support accessibility through clear composition
- feel timeless rather than trend-driven

Illustrations should complement the interface rather than compete with it.

## Main Character

### Character ID

CHAR-001

### Name

Bloom Girl

### Appearance

Hair: 

* Dark curly hair
* Usually in a soft bun
* Loose curls around the face

Eyes:

* Warm brown

Skin:

* Warm medium complexion
* Freckles - subtle across cheeks

Jewellery:

* Small gold hoop earrings
* Simple gold necklace


Clothing:

* Oversized sage knitwear
* Cream clothing
* Soft natural fabrics


Expression:

* Gentle
* Calm
* Kind
* Hopeful

### Personality

She is someone users should quietly relate to.

* celebrates small wins
* doesn't rush
* enjoys quiet mornings
* values rest
* reflects often
* enjoys nature
* isn't "perfect"

### Role within Bloom

The main character represents Bloom's calm and encouraging personality.

She is not intended to be a mascot in the traditional sense, but a relatable
presence that appears throughout the application to guide, encourage and
celebrate progress.

She should remain visually consistent across all future illustration packs.

# Approval Checklist

An illustration is approved when it:

- [ ] Matches Bloom's approved illustration style.
- [ ] Uses the official colour palette.
- [ ] Reinforces at least one Bloom value.
- [ ] Includes recognisable Bloom objects or botanical elements where appropriate.
- [ ] Is suitable for web, mobile and marketing use.
- [ ] Has no embedded UI text that cannot be localised.
- [ ] Meets accessibility and readability standards.
